Cesium ion: access to Google's 3D city

The 3D model of Burlington every frame is rendered from. Cesium's free plan includes Google's Photorealistic 3D Tiles, so there's no Google bill.

4 minfree
  1. Sign up (Google sign-in is fine): Cesium ion sign-up ↗
  2. Open Google's 3D tiles in the Asset Depot and click Add to my assets: Google Photorealistic 3D Tiles ↗
  3. Go to Access Tokens and click Create token: Access Tokens ↗
  4. Name it iso-burlington, keep the default scopes, and under Resources leave All assets selected. Create, then copy the token.
This one unblocks me first: I can start rendering Burlington as soon as I have it.

Cloudflare R2: where the map tiles live

I already created the bucket iso-burlington in your Cloudflare account. It needs an upload key and a public address. About 3 GB of tiles fits in R2's free tier.

4 minfree
  1. Open R2 API tokens and click Create Account API Token: R2 API tokens ↗
  2. Token name iso-burlington · Permissions Object Read & Write · Apply to specific buckets only → iso-burlington · TTL Forever. Create.
  3. Copy the three values on the next screen into the boxes below: Access Key ID, Secret Access Key, and the default S3 endpoint (starts with https:// and ends in r2.cloudflarestorage.com).
  4. Open the bucket's settings, find Public Development URL, click Enable, type allow and confirm. Copy the pub-….r2.dev address: Bucket settings ↗
